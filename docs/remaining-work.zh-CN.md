# 尚未完成的工作

核对日期：2026-09-23（钱包交接更新后）。目标是先完成一次“自然语言提出交易 → 程序风控 → 人工确认 → 钱包签名 → 核对成交”的真实演示。

当前已经真实验证：RWA 查询、钱包查询、NVDAon 的 SWAP 报价和交易构建、精确额度授权构建、授权模拟、缺失余额的 BSC balanceOf 查询。**授权模拟成功不等于兑换模拟成功，更不等于已经成交。** 外部签名器协议及成交核对代码有模拟测试，具体钱包和完整实盘尚未接通。

## P0：跑通第一笔交易

- [ ] 确定实际使用的钱包及公开地址、卖出代币、交易额度和 Gas 预算。
- [ ] 接入一个真实钱包：当前仅有外部签名器进程协议，需要实现钱包适配，处理账户/链校验、nonce、Gas、拒签及广播结果。
- [ ] 核实并配置可信 router/spender 白名单；示例白名单为空，不能直接从接口返回值自动放行。
- [ ] 使用自己的钱包确认并完成精确额度授权，等待授权回执。
- [ ] 授权后重新获取报价并构建交易，真实跑通兑换模拟。
- [ ] 完成一笔明确授权的小额主网交易，核对提交内容、回执及持仓变化并保存证据。

以上按已实测出现的 SWAP 路由实施；每次必须以接口返回的 executionMode 为准，不能保证下一次仍是同一路由。
